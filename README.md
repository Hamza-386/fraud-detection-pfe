# 🔍 Real-Time Fraud Detection System

## 📋 Description
Système de détection de fraude financière
en temps réel utilisant le Machine Learning
et le Deep Learning.

## 🛠 Technologies
- Python 3.10
- XGBoost / LightGBM
- TensorFlow / Keras
- FastAPI
- Streamlit
- Docker
- MLflow
- SHAP

## 📊 Dataset
IEEE-CIS Fraud Detection Dataset
- 590,540 transactions
- 434 features

## 🚀 Results
| Model | AUC Score |
|-------|-----------|
| LightGBM | ~0.96 |
| XGBoost | ~0.94 |
| Neural Network | ~0.93 |
